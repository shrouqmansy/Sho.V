# AI Workflow Rules

## Approach

- Build incrementally using spec-driven development.
- The Google Stitch output is the visual source of truth.
- Follow the Six-File Context Methodology.

## Scoping Rules

- Work on one component or section at a time.
- Verify component structure before assembling pages.
- Keep state management clean and localized.

## Protected Files

- Do not alter original Stitch reference files in `stitch_sho.v_premium_fashion_homepage/`.
- Do not overwrite methodology guidelines in `methodology/`.

## Keeping Docs in Sync

- Update `context/progress-tracker.md` after completing meaningful implementation milestones.

## Before Moving to Next Step

1. Clean build without syntax or runtime errors.
2. Verified visual matching against Stitch designs.
3. Tested responsive behavior.
