# UI Context

## Theme

Quiet luxury, minimal contemporary fashion. Warm ivory surfaces (`#fcfaf7` / `#fbf9f9`), deep charcoal typography (`#151616` / `#1b1c1c`), subtle taupe accents (`#6d5b49` / `#bc9c85`), low-contrast borders, and vast whitespace.

## Color Tokens

| Role | CSS Custom Property | Value | Description |
| --- | --- | --- | --- |
| Surface / Background | `--bg-surface` | `#fbf9f9` | Primary page & container background |
| Surface Container | `--bg-container` | `#f5f3f3` | Card & muted backgrounds |
| Surface High | `--bg-surface-high` | `#efeded` | Hover states |
| Primary Text / Border | `--color-primary` | `#151616` | Main body text, headers, primary buttons |
| Secondary Accent | `--color-secondary` | `#6d5b49` | Subtle interactive accents & buttons |
| Muted Text | `--color-muted` | `#747878` | Secondary labels & metadata |
| Border Default | `--border-color` | `#e4e2e2` | Low-contrast 1px separation lines |
| Sale / Discount | `--color-sale` | `#93000a` | Slashed price accent |

## Corner Radius & Shapes

- **Border Radius**: Strictly **0px** across all cards, containers, buttons, inputs, tags, and badges.

## Layout Spacing

- Desktop Margin: 80px
- Mobile Margin: 20px
- Section Gap: 120px
- Gutter: 24px
